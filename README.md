# 📊 NovaMart Retail Analytics

An end-to-end Retail Sales Analytics project built using **Python, SQL, and Power BI**.

This project demonstrates the complete data analytics workflow—from generating a realistic retail dataset using Python to performing Exploratory Data Analysis (EDA), SQL analysis, and building an interactive Power BI dashboard for business decision-making.

---

## 🚀 Project Overview

NovaMart is a fictional retail company.

This project was developed to analyze:

- Sales Performance
- Customer Behavior
- Product Performance
- Regional Insights
- Business KPIs

The project follows a complete analytics pipeline:

Dataset Generation → Data Cleaning → EDA → SQL Analysis → Power BI Dashboard
